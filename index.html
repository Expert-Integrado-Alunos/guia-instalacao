Etapa 1 · ObrigatórioPlano pago

Contratação do Claude ou do Codex

Você vai precisar de uma IA para usar o dia inteiro: conversar, gerar conteúdo, analisar planilhas, montar processos e construir o seu assistente com memória da empresa. Escolha um dos dois caminhos.

O Claude, da Anthropic, é a IA com que o evento é conduzido. Se você ainda não assina nenhuma IA, vá por aqui.

Qual plano contratar? Pro é o recomendado: US$ 20 por mês, ou US$ 17 por mês no plano anual, mais impostos. Atende o dia inteiro, já inclui o Claude Code e tem limite de uso suficiente. O Free tem limite muito baixo, e o Max só vale se você usa muito no dia a dia.

Como contratar

  1. Acesse claude.aiAbra claude.ai no navegador.
  2. Crie sua contaEntre com o Google, com a Apple ou com o e-mail principal da empresa.
  3. Confirme o celularNa primeira vez, o Claude manda um código de 6 dígitos por SMS. Número virtual ou telefone fixo não serve.
  4. Abra Configurações → FaturamentoClique no seu nome no canto inferior esquerdo → Configurações → Faturamento.
  5. Assine o ProClique em Atualizar plano → Obter plano Pro, escolha mensal ou anual, coloque os dados do cartão e clique em Inscrever-se.
Cobrança no cartão Se a cobrança vier em dólar, ela cai no cartão como compra internacional (com IOF e câmbio do dia). Você pode cancelar a qualquer momento, sem multa, em Configurações → Faturamento.
Pronto quando Em claude.ai, no seu nome → Configurações → Faturamento, o seu plano aparece como Pro.

O Codex é o agente da OpenAI que faz o mesmo papel do Claude Code: trabalha dentro de uma pasta do seu computador, lê arquivos e executa tarefas. Ele vem incluído no plano do ChatGPT.

Antes de escolher este caminho O evento é conduzido com o Claude. Use o Codex se você já assina o ChatGPT e prefere ficar nele.
Qual plano contratar? O Codex vem nos planos do ChatGPT, inclusive no gratuito, mas no Free e no Go o uso é mais limitado. Para acompanhar o dia inteiro, use o Plus ou superior. No Brasil, o Plus custa R$ 99,90 por mês (só tem plano mensal).

Como contratar

  1. Acesse chatgpt.com e entrechatgpt.com. Se ainda não tem conta, clique em Cadastre-se grátis e use o e-mail principal da empresa.
  2. Assine o PlusClique no ícone do seu perfil → Atualizar plano → Obter Plus, coloque os dados do cartão e confirme a assinatura. Planos e valores em chatgpt.com/pricing.
Pronto quando Você entra em chatgpt.com, faz login, e o seu plano aparece como Plus (ou superior) nas configurações.

Etapa 2 · ObrigatórioGratuito

Preparar o Computador

Antes de instalar o app da etapa 3, instale duas ferramentas de apoio gratuitas: o Git e o Node.js. Leva cerca de 10 minutos e evita travas durante o evento.

Por que preciso disso? O Claude Desktop (etapa 3) já vem com o Claude Code dentro, mas ele não instala o Git nem o Node.js. No Windows, a aba Code pede o Git na primeira vez que é aberta; e os aplicativos que você vai criar no evento geralmente precisam do Node.js para rodar no seu computador. Vale o mesmo para quem for usar o Codex.

Como instalar

1. Instalar o Git

  1. Acesse git-scm.com/downloads/wingit-scm.com/downloads/win. Baixe o instalador 64-bit para Windows (primeiro link da página).
  2. Execute o instalador e avance em tudoO instalador mostra muitas telas de opções. Não mude nada: clique em Next até o fim e depois em Install. As opções padrão são exatamente as que precisamos.
A aba Code pediu o Git? Se o Claude Desktop já estava instalado e a aba Code mostrou um aviso pedindo o Git, é este passo que resolve. Instale, feche e abra o app de novo.

2. Instalar o Node.js

  1. Acesse nodejs.org/pt/downloadnodejs.org/pt/download. Ignore o bloco de comandos no topo da página: é instalação via Docker, você não precisa dele.
  2. Desça até "Ou baixe uma versão pré-compilada"Confira se o seletor mostra Windows e clique no botão verde Instalador Windows (.msi).
  3. Execute o instaladorAbra o arquivo .msi baixado, aceite as opções padrão e clique em Next até o fim.

1. Ativar o Git

No Mac, o Git vem junto com as "ferramentas de linha de comando" da Apple. Só precisa ativar.

  1. Abra o TerminalAperte Cmd + Espaço, digite Terminal e aperte Enter.
  2. Copie o comando abaixo, cole no Terminal e aperte Enter 
    git --version
  3. Siga conforme o que aparecerApareceu uma janela perguntando se quer instalar as ferramentas de linha de comando? Clique em Instalar, aceite os termos e aguarde (5 a 10 min). Apareceu um número de versão (ex.: git version 2.39)? Seu Mac já está pronto, pule para o Node.js.

2. Instalar o Node.js

  1. Acesse nodejs.org/pt/downloadnodejs.org/pt/download. Ignore o bloco de comandos no topo da página: é instalação via Docker, você não precisa dele.
  2. Desça até "Ou baixe uma versão pré-compilada"Troque o seletor para macOS e clique no botão verde Instalador macOS (.pkg).
  3. Execute o instaladorAbra o arquivo .pkg baixado, aceite as opções padrão e conclua.
Precisa de conta no GitHub? Não. O Git é um programa que roda no seu computador. O GitHub é um site para publicar código na internet. São coisas diferentes, e nada no evento exige conta no GitHub.
Pronto quando Windows: o Git Bash aparece no menu Iniciar.
Mac: git --version no Terminal mostra um número de versão.
Os dois: node --version no terminal mostra a versão do Node, e a aba Code do Claude Desktop abre sem pedir nenhuma instalação.

Etapa 4 · ObrigatórioGratuito

Voice AI

Aplicativo da Expert Integrado para transcrever a sua voz com IA. Você aperta um atalho do teclado, fala, e o texto aparece onde o cursor estiver, em qualquer programa do Windows ou do Mac.

Um presente para quem participa da imersão O Voice AI foi criado pela Expert Integrado e é liberado só para os alunos. Como participante da imersão, você ganha o acesso de presente. Quando a meta é digitar o mínimo possível, é ele que destrava isso.

Requisitos

  • Windows: Windows 10 ou 11, 64 bits.
  • Mac: chip Apple (M1 ou mais novo, com macOS 14 ou mais novo) ou processador Intel (com macOS 13.4 ou mais novo). Ao baixar, o site pergunta qual é o seu. Para conferir: menu Apple (canto superior esquerdo) → Sobre Este Mac. Se o Voice AI não rodar no seu computador, use o Handy, em Outra opção: Handy, no fim desta etapa.

Modos de transcrição

Na maior parte dos casos, o modo Local é suficiente.

  • Local: roda no seu computador, sem internet. Gratuito. Recomendado para computadores com 8 GB de RAM ou mais.
  • Online: mais rápido, usa a internet. Precisa de uma chave: grátis da Groq (recomendada, passo a passo abaixo) ou paga da OpenAI (centavos por minuto, tutorial oficial da OpenAI).

Como instalar

  1. Acesse voiceai.expertintegrado.com.brvoiceai.expertintegrado.com.br
  2. Clique em "Baixar para Windows"Preencha nome, e-mail, WhatsApp e empresa para liberar o download. Se o Chrome avisar sobre o arquivo, clique em Manter.
  3. Abra o instalador baixadoNão pede senha de administrador.
  4. Apareceu uma tela azul? Libere a instalaçãoClique em Mais informações e depois em Executar assim mesmo. A instalação segue normalmente.
  5. Informe o seu e-mailNo primeiro uso, o app pede o seu e-mail.
Aviso azul do Windows? É normal Ele aparece porque o instalador ainda não tem assinatura digital. Se o antivírus pedir permissão, autorize.
  1. Acesse voiceai.expertintegrado.com.brvoiceai.expertintegrado.com.br
  2. Clique em "Baixar para Mac"Preencha nome, e-mail, WhatsApp e empresa para liberar o download.
  3. Abra o arquivo .dmg e arraste o app para a pasta AplicativosNo Mac, o app se chama Voice AI 2.
  4. Abra o app e libere a aberturaNa primeira vez, o macOS avisa que não verificou o desenvolvedor. Vá em Ajustes do Sistema → Privacidade e Segurança, role até Segurança e clique em Abrir Mesmo Assim.
  5. Aceite as 3 permissõesMicrofone, Monitoramento de Entrada e Acessibilidade. Se o Mac abrir os Ajustes do Sistema, ligue a chave do Voice AI 2 em cada um desses itens, dentro de Privacidade e Segurança.
Depois de atualizar, o Mac pede de novo O app se atualiza sozinho. Enquanto ele não tem o selo da Apple, cada atualização pede as 3 permissões outra vez: libere do mesmo jeito.
Pronto quando O app está instalado e, ao apertar o atalho (Ctrl + Alt + S no Windows, Ctrl + Option + S no Mac), falar e apertar de novo, o texto aparece onde o cursor está.

Quando os 30 dias de teste acabam, o app pede um código de ativação: quem libera é a equipe da Expert Integrado, e na mesma tela do app tem um botão para falar com a equipe (perguntas do site do Voice AI).

Opcional: deixe mais rápido com a chave grátis da Groq

A Groq é um serviço de IA com plano gratuito (sem cartão) que transcreve muito rápido. Você cria uma chave nela e cola no Voice AI. Vale para Windows e Mac. O vídeo do topo desta etapa mostra o passo a passo, com a chave da Groq e a da OpenAI, a partir de 4:15.

  1. Crie sua conta na GroqAcesse console.groq.com e crie sua conta. O plano Free é gratuito.
  2. Gere a chaveAbra API Keys, clique em Create API Key, dê um nome (ex.: Voice AI) e copie a chave. Ela começa com gsk_. Copie na hora: se perder, é só criar outra.
  3. Cole no Voice AINo Voice AI, vá em Configurações, cole no campo Chave (Groq ou OpenAI) e clique em Salvar chave.
  4. Ligue o modo OnlineEm Transcrição → Onde transcrever, escolha Online (Groq ou OpenAI).
A chave é pessoal Funciona como uma senha: não mande por WhatsApp, não poste e não mostre em print. Se vazar, apague a chave em API Keys na Groq e crie outra.

Não achou o campo de chave? Atualize o Voice AI para a versão mais recente.

Outra opção: Handy Se o Voice AI não rodar no seu computador, use o Handy: gratuito, de código aberto e roda no seu computador, sem internet. Mesma ideia: aperta o atalho, fala, e o texto aparece onde o cursor estiver.
