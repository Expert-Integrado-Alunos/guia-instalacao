Etapa 1 · ObrigatórioPlano pago

Contratação do Claude ou do Codex

Você vai precisar de uma IA para usar o dia inteiro: conversar, gerar conteúdo, analisar planilhas, montar processos e construir o seu assistente com memória da empresa. Escolha um dos dois caminhos.

O Claude, da Anthropic, é a IA com que o evento é conduzido. Se você ainda não assina nenhuma IA, vá por aqui.

Qual plano contratar? Pro (~US$ 20/mês, cerca de R$ 90) é o recomendado. Atende o dia inteiro, libera o Claude Code e tem limite de uso suficiente. O Free tem limite muito baixo, e o Max só vale se você usa muito no dia a dia.

Como contratar

  1. Acesse claude.aiAbra claude.ai no navegador.
  2. Crie sua contaUse o e-mail principal da empresa.
  3. Faça login e abra SettingsClique no seu nome no canto inferior esquerdo → Settings → Plans.
  4. Selecione o plano ProFinalize com cartão de crédito.
Pagamento em dólar O valor cai no cartão como compra internacional (com IOF e câmbio do dia). Você pode cancelar a qualquer momento, sem multa.
Pronto quando Você entra em claude.ai, faz login, e o selo ao lado do seu nome mostra Pro.

O Codex é o agente da OpenAI que faz o mesmo papel do Claude Code: trabalha dentro de uma pasta do seu computador, lê arquivos e executa tarefas. Ele vem incluído no plano do ChatGPT.

Antes de escolher este caminho O evento é conduzido com o Claude. Use o Codex se você já assina o ChatGPT e prefere ficar nele.
Qual plano contratar? O Codex vem nos planos do ChatGPT, inclusive no gratuito, mas no Free e no Go o uso é mais limitado. Para acompanhar o dia inteiro, use o Plus ou superior.

Como contratar

  1. Acesse chatgpt.com e faça loginchatgpt.com. Se ainda não tem conta, crie com o e-mail principal da empresa.
  2. Confira ou contrate o planoVeja os planos e valores em chatgpt.com/pricing.
Pronto quando Você entra em chatgpt.com, faz login, e o seu plano aparece como Plus (ou superior) nas configurações.

Etapa 2 · ObrigatórioGratuito

Preparar o Computador

Antes de instalar o app da etapa 3, instale duas ferramentas de apoio gratuitas: o Git e o Node.js. Leva cerca de 10 minutos e evita travas durante o evento.

Por que preciso disso? O Claude Desktop (etapa 3) já vem com o Claude Code dentro, mas ele não instala o Git nem o Node.js. No Windows, a aba Code pede o Git na primeira vez que é aberta; e os aplicativos que você vai criar no evento geralmente precisam do Node.js para rodar no seu computador. Vale o mesmo para quem for usar o Codex.

Como instalar

1. Instalar o Git

  1. Acesse git-scm.com/downloads/wingit-scm.com/downloads/win. Baixe o instalador 64-bit para Windows (primeiro link da página).
  2. Execute o instalador e avance em tudoO instalador mostra muitas telas de opções. Não mude nada: clique em Next até o fim e depois em Install. As opções padrão são exatamente as que precisamos.
A aba Code pediu o Git? Se o Claude Desktop já estava instalado e a aba Code mostrou um aviso pedindo o Git, é este passo que resolve. Instale, feche e abra o app de novo.

2. Instalar o Node.js

  1. Acesse nodejs.org/pt/downloadnodejs.org/pt/download. Ignore o bloco de comandos no topo da página: é instalação via Docker, você não precisa dele.
  2. Desça até "Ou baixe uma versão pré-compilada"Confira se o seletor mostra Windows e clique no botão verde Instalador Windows (.msi).
  3. Execute o instaladorAbra o arquivo .msi baixado, aceite as opções padrão e clique em Next até o fim.

1. Ativar o Git

No Mac, o Git vem junto com as "ferramentas de linha de comando" da Apple. Só precisa ativar.

  1. Abra o TerminalAperte Cmd + Espaço, digite Terminal e aperte Enter.
  2. Copie o comando abaixo, cole no Terminal e aperte Enter 
    git --version
  3. Siga conforme o que aparecerApareceu uma janela perguntando se quer instalar as ferramentas de linha de comando? Clique em Instalar, aceite os termos e aguarde (5 a 10 min). Apareceu um número de versão (ex.: git version 2.39)? Seu Mac já está pronto, pule para o Node.js.

2. Instalar o Node.js

  1. Acesse nodejs.org/pt/downloadnodejs.org/pt/download. Ignore o bloco de comandos no topo da página: é instalação via Docker, você não precisa dele.
  2. Desça até "Ou baixe uma versão pré-compilada"Troque o seletor para macOS e clique no botão verde Instalador macOS (.pkg).
  3. Execute o instaladorAbra o arquivo .pkg baixado, aceite as opções padrão e conclua.
Precisa de conta no GitHub? Não. O Git é um programa que roda no seu computador. O GitHub é um site para publicar código na internet. São coisas diferentes, e nada no evento exige conta no GitHub.
Pronto quando Windows: o Git Bash aparece no menu Iniciar.
Mac: git --version no Terminal mostra um número de versão.
Os dois: node --version no terminal mostra a versão do Node, e a aba Code do Claude Desktop abre sem pedir nenhuma instalação.

Etapa 4 · ObrigatórioGratuito

Voice AI

Aplicativo da Expert Integrado para transcrever a sua voz com IA. Você aperta um atalho do teclado, fala, e o texto aparece onde o cursor estiver, em qualquer programa do Windows.

Por que vale a pena Quando a meta é digitar o mínimo possível, o Voice AI é a ferramenta que destrava isso.

Disponibilidade

  • Windows 10 e 11: disponível agora, gratuito.
  • Mac: em breve. Veja as alternativas no fim desta seção.

Modos de transcrição

Na maior parte dos casos, o modo Local é suficiente.

  • Local: roda no seu computador, sem internet. Gratuito. Recomendado para PCs com 8 GB de RAM ou mais.
  • Online: mais rápido, usa a internet. Precisa de uma chave: grátis da Groq (recomendada, passo a passo abaixo) ou paga da OpenAI (centavos por minuto, tutorial oficial da OpenAI).

Como instalar (Windows)

  1. Acesse voiceai.expertintegrado.com.brvoiceai.expertintegrado.com.br
  2. Clique em "Baixar Gratuitamente"
  3. Preencha seus dados para liberar o download
  4. Execute o instalador baixado
Aviso azul do Windows? É normal Pode aparecer "O Windows protegeu o seu computador". Faça assim:
  1. Clique em Mais informações.
  2. Vai aparecer Executar assim mesmo. Clique.
  3. A instalação segue normalmente.

O app é seguro: o aviso aparece porque a assinatura digital ainda está em certificação. Se o antivírus pedir permissão, autorize.

Pronto quando O app está instalado, o atalho de teclado está configurado, e ao apertar e falar o texto aparece onde o cursor está.

Opcional: deixe mais rápido com a chave grátis da Groq

A Groq é um serviço de IA com plano gratuito (sem cartão) que transcreve muito rápido. Você cria uma chave nela e cola no Voice AI.

  1. Crie sua conta na GroqAcesse console.groq.com e crie sua conta. O plano Free é gratuito.
  2. Gere a chaveAbra API Keys, clique em Create API Key, dê um nome (ex.: Voice AI) e copie a chave. Ela começa com gsk_. Copie na hora: se perder, é só criar outra.
  3. Cole no Voice AINo Voice AI, vá em Configurações, cole no campo Chave (Groq ou OpenAI) e clique em Salvar chave.
  4. Ligue o modo OnlineEm Transcrição → Onde transcrever, escolha Online (Groq ou OpenAI).
A chave é pessoal Funciona como uma senha: não mande por WhatsApp, não poste e não mostre em print. Se vazar, apague a chave em API Keys na Groq e crie outra.

Não achou o campo de chave? Atualize o Voice AI para a versão mais recente.

Alternativa para Mac

Até o Voice AI chegar ao Mac, use o Handy: gratuito, de código aberto e roda no seu computador, sem internet. Mesma ideia: aperta o atalho, fala, e o texto aparece onde o cursor estiver.
